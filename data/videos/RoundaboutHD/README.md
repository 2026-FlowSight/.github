Toto je dataset RoundaboutHD, link je tu: https://huggingface.co/datasets/yl4300/RoundaboutHD/tree/main 
Ale je to pre github moc veľké, kamery sú origo 4k 15fps, ja som ich prerobil do HD, 1min, 15fps, skripty upravujú fps alebo si to prekonvertujte cez ffmpeg.
Kamery sú rozložené podľa layoutu, takže je možné vidieť auto z kamery 1 do kamery 2 atď., toto je najbližšie skutočným kamerám.
Ak je vám málo výrezov, tak dataset obsahuje RoundaboutHD_Reid_subset a tam je strašne moc výrezov pre trénovanie a test.
